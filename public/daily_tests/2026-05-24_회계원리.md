1단계 (S1 배분): S1 원가 100,000을 S2(20%), P1(30%), P2(50%)에 배분합니다. => S2에 배분 = 100,000 × 20% = 20,000 => P1에 배분 = 100,000 × 30% = 30,000 => P2에 배분 = 100,000 × 50% = 50,000
2단계 (S2 배분): S2의 배분대상 총원가 = 자기 발생액(80,000) + S1으로부터 받은 금액(20,000) = 100,000. S2는 S1(10%), P1(40%), P2(60%)로 용역을 제공하나, S1으로는 역배분하지 않으므로 P1과 P2의 제공비율(40:60)만으로 100% 비율을 재산정하여 배분합니다. (40% / 100% = 40%) => P1에 배분 = 100,000 × 40% = 40,000
결론: P1에 최종 배분되는 보조부문원가 총액 = S1으로부터 받은 금액(30,000) + S2로부터 받은 금액(40,000) = ￦70,000.

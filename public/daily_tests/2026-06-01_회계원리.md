목표 매출액 = (총고정원가 + 세전 목표이익) / 공헌이익률

자가제조 시 관련원가(회피가능원가):
단위당 제조 관련원가 = 직접재료(200) + 직접노무(150) + 변동제조간접(100) + 회피가능 고정제조간접(250 × 40% = 100) = ￦550.
자가제조 시 총 관련원가 = 5,000단위 × 550 = ￦2,750,000.
외부구입 시 관련원가:
부품 구입대금 = 5,000단위 × 500 = ￦2,500,000.
외부구입 시 원가 절감액 = 2,750,000(제조비용) - 2,500,000(구입비용) = ￦250,000.
기회비용 고려(임대수익): 외부 구입 시 설비 임대로 ￦100,000의 수익이 추가 창출됩니다.
영업이익 증감액 = 원가 절감액(250,000) + 임대수익(100,000) = ￦350,000. 따라서 외부 구입 제안을 수락하면 영업이익이 ￦350,000 증가합니다.
